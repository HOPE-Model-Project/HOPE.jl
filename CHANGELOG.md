# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Standard file-backed DART cases through `run_hope` and `validate_hope`,
  including installed-system manifests, stable IDs, initial operational state,
  native subhourly realization files, acceptance checks, and standard outputs.
- Standalone RTS24 DART reference case with all compatible constraint families.

### Changed

- DART static generator and storage attributes now live in the canonical
  `gendata.csv` and `storagedata.csv` inputs.
- Shared model-mode validation and HOPE-AI tooling now recognize DART. The MCP
  output summary reports DART acceptance, constraint coverage, settlement, and
  solver status; dashboard requests return an explicit unsupported-mode error.

## [2.0.0] - 2026-10-01

### Breaking

- Transmission input now requires directional `Forward Capacity (MW)` and
  `Reverse Capacity (MW)` columns instead of the former symmetric
  `Capacity (MW)` column. Existing cases must add both directional columns;
  use the former capacity value for each direction to preserve symmetric limits.

### Added

- Lightweight in-memory DART SCUC, SCED, generator N-1, rolling, and settlement
  functionality.

### Changed

- Add `clean_energy_policy = 2` for local annual RPS compliance without
  renewable-credit trading variables, and avoid allocating RPS variables when
  clean-energy policy is disabled.
- Replaced the symmetric transmission input `Capacity (MW)` with required
  `Forward Capacity (MW)` and `Reverse Capacity (MW)` ratings in GTEP and PCM.
  Existing and candidate lines, nodal branches, loss bounds, holistic/EREC
  handoffs, and congestion outputs now preserve line direction explicitly.
- Avoid GTEP resource-hour SPIN variables and zero-fixing constraints when
  `operation_reserve_mode = 0`; zero-valued expressions preserve the same
  downstream algebra with substantially lower model-construction overhead.

### Fixed

- Use HiGHS in solver-backed constraint tests and run macOS CI on the native
  runner architecture so the test suite works on Apple Silicon.
- Restore authenticated Codecov uploads and track coverage against the `main`
  branch.
- Preserve candidate input capacities during GTEP solve diagnostics and derive built
  generator, storage, and transmission capacities explicitly in output writing. This
  prevents fractional build decisions from being applied twice in `system_cost.csv`.
- Reject multiple `Time Period` values in full chronological mode so hourly
  storage state-of-charge transitions cannot be silently omitted.
- Select full-year storage boundary equations from the configured temporal
  mode instead of inferring the mode from the input period IDs.
- Scale candidate renewable curtailment by the candidate build decision.

## [1.1.0] - 2026-04-08

### Added

- Endogenous representative-day selection (`src/rep_day.jl`): automatically
  select and weight a small set of representative days from a full chronology
  using k-medoids clustering, optional extreme-day augmentation, and
  planning-oriented feature engineering.
- Resource aggregation (`src/aggregation.jl`): group generators by technology
  type and zone to reduce model size while preserving system-level behaviour.
- Holistic GTEP→PCM two-stage planning workflow (`src/run_holistic.jl`):
  `run_hope_holistic` and `run_hope_holistic_fresh` inject GTEP capacity
  decisions into a PCM case and solve both models in sequence.
- EREC (Energy Resilience and Efficiency Criterion) module (`src/erec.jl`):
  compute energy-resilience metrics from PCM or GTEP dispatch output.
- Nodal PTDF-based DC OPF (`network_model = 3`) for PCM.
- Flexible demand response in PCM (`flexible_demand = 1`).
- Shadow-price extraction via optional LP re-solve after MILP solve
  (`write_shadow_prices = 1`).
- `HOPE_MODELCASES_PATH` environment variable to locate model cases stored
  outside the HOPE repository.
- New reference cases: ISO-NE 250-bus nodal PCM (`ISONE_PCM_250bus_case`),
  Germany PCM case suite (nodal and 4-zone), RTS-24 multi-zone congestion
  case, and holistic Maryland full-8760 benchmark.
- Interactive web dashboard (`tools/hope_dashboard`) powered by Plotly Dash.
- GitHub Pages documentation site generated by Documenter.jl.

### Changed

- Default open-source solver switched from Cbc to HiGHS.
- Solver loading is now lazy-guarded; unavailable solvers are skipped
  gracefully without halting package load.
- CI matrix extended to Ubuntu, macOS, and Windows on Julia 1 and nightly.
- `DataFrames` compat broadened from `"1.8"` to `"1"`.
- `DataStructures` compat broadened from `"0.19"` to `"0.18, 0.19"`.

### Fixed

- `using HiGHS` world-age issue resolved by removing `@eval` wrapper.
- CSV `DataFrame` constructor deprecation (positional column argument).
- `NumUnits` column preserved through resource aggregation in PCM.

## [1.0.0] - 2024-02-02

Initial release of the current HOPE Julia package.

### Added

- Generation and Transmission Expansion Planning (GTEP) model.
- Production Cost Model (PCM) with zonal and copper-plate network options.
- Benchmark cases: IEEE-14, IEEE-118, RTS-24, Maryland, and PJM-MD100.
- Multi-solver support: HiGHS, GLPK, Clp, Cbc; optional Gurobi and SCIP.
- XLSX and CSV input data formats.
